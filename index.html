How each match is predicted

1 · Class / spec odds

// W = wins (ties count ½), N = games, all from the Swiss v_class = (W + 5) / (N + 10) A's class vs B's class v_cs = (W + 10·v_class) / (N + 10) A's class vs B's spec v(A,B) = (W + 10·v_cs) / (N + 10) A's spec vs B's spec p_class = ½ · [ v_class(A,B) + 1 − v_class(B,A) ] Class mode stops here p_spec = ½ · [ v(A,B) + 1 − v(B,A) ] Spec mode stops here

Each level is pulled toward the broader one, so a spec matchup with only a few games leans on the class numbers. Both players' views are averaged. Mirror specs are set to 50%.

2 · Player adjustment

Δ = (r − p_ref) · n² / (n² + 8) p = p_spec + Δ_A − Δ_B clamped to 3–97%

r = the player's own Swiss win rate against the opponent's spec (or class, if they never met that spec), n = how many of those games they played, p_ref = their spec odds (p_spec for A, 1 − p_spec for B). The n²/(n²+8) weight makes one game count a little and several games count a lot. A player with no games gets Δ = 0, so they don't water down the other player's record.

3 · Series odds

Bo1 = p Bo3 = p² · (3 − 2p) Bo5 = p³ · (10 − 15p + 6p²)

The single-game chance p is turned into the chance to win the series. The percentages on the bracket are these series odds.

4 · Picking the winner

The player above 50% advances. An exact 50% (same spec, same records) goes to the higher seed. Winners and losers then move through the real double-elimination bracket, so later rounds use the predicted players.
